# logbook

a cli tool to write your own diary,so you can trace your memories and works

it meant to create a simple tool to write about you,you're the only one who should read it,
save your projects,your stories,your memories,this should be something private,so i made it open source,anyone can read and modify this code to use it himself but i also created this tool to
give your story to AI,i would like to have my own AI that thinks and speaks like me,
so i can see myself from another prospective.

## about the project

run it

``` bash
logbook
```
